# Netflix Content Analysis

Exploratory data analysis of 8,807 Netflix titles using Python, Pandas, Matplotlib, and Seaborn.

## What I did
- Cleaned the dataset (handled missing values, removed duplicates, parsed dates)
- Built 4 visualizations:
  1. Movies vs TV Shows distribution
  2. Content added per year (trend)
  3. Top 10 countries producing content
  4. Content rating distribution

## Tools
Python, Pandas, Matplotlib, Seaborn, Google Colab

## Dataset
[Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows) — Kaggle
